# Fullstack Starter (Go + Fiber, Next.js, PostgreSQL)

Kerangka project fullstack monorepo sebagai fondasi aplikasi: REST API dengan
Go + Fiber, web app dengan Next.js (App Router + TypeScript), dan PostgreSQL
sebagai database. Semua service dapat dijalankan dengan Docker Compose.

Project ini juga menyertakan satu contoh fitur CRUD (`items`) untuk membuktikan
bahwa frontend, backend, dan database sudah terhubung dengan benar.

> Dokumentasi lengkap (prasyarat, cara menjalankan, environment variable,
> endpoint API, dan struktur folder) ditambahkan pada tahap akhir.
